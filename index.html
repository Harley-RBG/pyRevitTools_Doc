Internal tools wiki and training hub Editable in working-hub.json

Central searchable place for training, documentation, and tool discovery across Revit tools, Windows apps, and web-based apps.

  • Tool catalogue: list each tool and what problem it solves.
  • Training mode: simulate behavior with dummy data before live usage.
  • Project safety: identify whether a tool edits views, sheets, parameters, files, or model data.
  • Shared learning: capture known fixes, helper patterns, and examples for new tools.
  • Broader scope: include pyRevit tools, package utilities, verification tools, and desktop apps.
