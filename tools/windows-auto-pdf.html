Auto-PDF is a focused, standalone PDF ordering and merging utility for engineering drawing sets. It takes a folder of PDFs, a multi-page PDF, or individually selected files and lets you reorder the pages — manually via drag-and-drop, or automatically by extracting drawing numbers directly from a defined region of the PDF titleblock — then exports the result as a single merged PDF.

Auto-PDF is the standalone version of the PDF-ordering engine that is also embedded within Issue Package Creator. It is designed to be lightweight, single-purpose, and fully self-contained — the Tesseract OCR runtime is bundled with the EXE so no separate installation is required.

Workflow Step-by-step PDF ordering and merging process

Source Modes

📄 Multi-page PDF A single PDF file — each page becomes a row in the order table.
📁 Folder of PDFs A folder of individual PDF files — each file becomes a row.
🗂️ Individual Files Manually select specific PDF files to include.
↕️ Drag & Drop Drag PDFs or a folder directly onto the table to add or replace the current set.
  1. Load PDFs
    Use one of the source mode buttons (Pick PDF, Pick Folder, Pick Files) or drag-and-drop files or a folder onto the table. All pages or files appear as rows in the ordering table with their filename or page number.
  2. View and manually reorder
    Drag rows in the table to reorder them, or use the Move Up / Move Down buttons. The current order is automatically saved per source folder/file and restored on next load.
  3. Pick a region for auto-sort (optional)
    Click Pick Region… to open the Region Picker Dialog. A zoomable PDF preview is shown — drag to draw a rectangle over the drawing number area of the titleblock. Optionally enter a regex to isolate just the number from surrounding text. Click Confirm to save the region.
  4. Sort by drawing number
    Click Sort Pages by Region. The app extracts the drawing number from the defined region for every page/file using PyMuPDF vector-text extraction first, falling back to Tesseract OCR only when no selectable text is found. Rows are then sorted by the extracted value.
  5. Apply a saved titleblock profile (optional)
    If a named titleblock profile already exists for your drawing set, select it from the Profile combo to load its region settings rather than picking manually.
  6. Export merged PDF
    Click Export PDF. The app merges all pages/files in the current order into a single output PDF using pypdf. Choose the output path in the save dialog.
Key Features Capabilities and modules
Three Source Modes

Load from a multi-page PDF, a folder of PDFs, or individually selected files. All modes support drag-and-drop onto the table.

Drag-and-Drop Reordering

Rows in the table are drag-and-drop enabled. Move Up / Move Down buttons also available for precise single-step reordering.

Interactive Region Picker

Zoomable PDF preview with drag-to-draw rectangle selection. Choose the page to pick from using a page spin box.

Vector-Text-First OCR

PyMuPDF extracts selectable text from the defined region first. Tesseract is only invoked as a fallback, keeping the process fast and accurate.

Regex Filtering

An optional regex field isolates just the drawing number from any surrounding text extracted from the region, improving sort accuracy.

Saved Page Order

The current order is persisted per source (folder or file) in pdf_order.json. Automatically restored when the same source is loaded again.

Saved Region Settings

Region definitions (rectangle coordinates + regex) are persisted per project in region_settings.json.

Titleblock Profiles

Reusable named region profiles (shared or per-user) mean you only define a region once per titleblock type.

Portable Tesseract

A portable Tesseract runtime is bundled in third_party/tesseract/win64/, making the EXE fully self-contained. No separate Tesseract installation needed.

Single-Window Design

No tabs — the entire app is a single focused workflow window. Minimal setup, immediate productivity.

User Interface Controls and dialogs

Main Window Controls

The app is a single window. All controls are in the main PdfOrderWidget:

  • Pick PDF — load a single multi-page PDF (each page = one row)
  • Pick Folder — load all PDFs from a folder (each file = one row)
  • Pick Files — manually select individual PDF files
  • PdfOrderTableView — drag-drop enabled table; columns include filename/page number and extracted drawing number
  • Move Up / Move Down — single-step manual row reordering
  • Delete / Clear — remove selected rows or clear the entire table
  • Pick Region… — opens the Region Picker Dialog to define the titleblock extraction zone
  • Regex field — optional pattern to filter extraction text
  • Titleblock profile combo — load a named profile's saved region settings
  • Sort Pages by Region — triggers OCR-based auto-sort using the defined region
  • Export PDF — writes the reordered pages/files into a single merged output PDF

Region Picker Dialog

  • ZoomablePickView — scroll-wheel zoom on the PDF page preview; drag to draw the selection rectangle
  • Page spin box — choose which PDF page to use as the template for region picking
  • Preview text display — shows a live extraction result from the selected region as you draw
  • Confirm / Cancel buttons
Developer Notes Architecture, file structure, and dependencies

Architecture

Auto-PDF is a single-window PySide6 application. The main window hosts a single PdfOrderTab widget which composes the PdfOrderWidget. The table is backed by a PdfOrderTableModel (Qt item model). Packaged as a standalone .exe via PyInstaller with a bundled Tesseract runtime at third_party/tesseract/win64/.

Key Source Files

  • main.py — app entry point + telemetry setup
  • ui/tabs/pdf_order_tab.py — main tab widget
  • ui/models/pdf_order_model.py — Qt table model for PDF/page ordering
  • ui/dialogs/region_picker_dialog.py — interactive region picker with zoomable PDF view
  • backend/region_ocr.py — PDF region extraction (vector-text + Tesseract fallback)
  • backend/pdf_order_store.py — save/load/delete page order per source
  • backend/region_settings.py — region definition persistence per project
  • backend/titleblock_registry.py — named profile discovery

User Data Location

  • %APPDATA%\Auto-PDF\users\<username>\pdf_order.json — saved page order per source
  • %APPDATA%\Auto-PDF\users\<username>\region_settings.json — saved region definitions
