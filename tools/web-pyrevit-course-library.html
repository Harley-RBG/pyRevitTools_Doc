Overview
← Back to Web Apps

The pyRevit Course Library is the learning portal for pyRevit tooling and internal workflows. It provides structured modules, examples, and guided walkthroughs for onboarding and continuous upskilling.

How It Works
  • Users open the library and choose a topic area.
  • Each module presents practical steps, examples, and expected outcomes.
  • Content can be paired with simulator pages for safe training before project use.
  • Teams can standardize learning paths for new starters and discipline-specific workflows.
Core Functions
  • Central training catalog for pyRevit and related tooling.
  • Reusable course structure with clear progression.
  • Reference companion to tool wiki pages and implementation notes.
Notes

Recommended audience: BIM leads, model managers, and project delivery teams adopting internal pyRevit workflows.
