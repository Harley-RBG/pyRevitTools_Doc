Overview

The pyRevit Tools Wiki is the central web portal for internal tool discovery and training. It unifies Revit tool catalog data, Windows/Web app inventories, and simulator experiences into one searchable experience.

How It Works
  • Home Spaces: users choose Extension, Windows Apps, or Web Apps.
  • Extension Space: browse parsed tool cards with metadata, purpose, and files.
  • Wiki Pages: open dedicated app/tool pages for workflows and developer notes.
  • Training Simulator: run safe mock interactions for selected tools.
Core Functions
  • Tool catalog generated from extension metadata.
  • Working hub sections for ideas, standards, and ongoing implementation notes.
  • Windows/Web app catalogs with links, status, and wiki pages.
  • User add-app wizard support (local browser persistence).
Notes

This app is the anchor point for all companion wiki pages in the tools/ folder and should stay aligned with updates in working-hub.json.
