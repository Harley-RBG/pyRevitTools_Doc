Issue Package Verifier is an engineering drawing package quality-assurance tool. Given an Excel drawing register and a set of PDFs — from a local folder, individual files, a multi-page PDF, or cloud files from Autodesk Construction Cloud (ACC) — it validates that every drawing is present in both sources, and that drawing numbers, sheet names, and revisions are consistent across the register and the physical PDFs.

The app uses a configurable authority order to resolve conflicts between sources (Excel register, OCR from PDF titleblock, filename, revision table). Results are presented as a colour-coded comparison table and can be exported as an Excel or PDF verification report.

Workflow Step-by-step verification process
  1. Load the Excel drawing register
    Select an .xlsx drawing register. The Excel Mapping Dialog lets you map spreadsheet columns to fields (drawing number, revision, date, sheet name, status). All rows are read into structured ExcelRow objects.
  2. Load PDFs
    Use the Load PDF Wizard to choose a source: a folder of individual PDFs, a single multi-page PDF, manually selected files, or browse an Autodesk Construction Cloud project via an in-app OAuth2 browser login. Each PDF is parsed into FileEntry objects with drawing number and revision extracted from the filename.
  3. Select a titleblock profile
    Choose a JSON titleblock profile that defines the regions on the PDF page to extract: sheet number box, revision box, revision table, etc. Profiles can be managed and created in the Titleblocks tab.
  4. Run OCR (optional)
    A background OcrWorker thread processes each PDF's titleblock regions using PyMuPDF vector-text first, falling back to Tesseract if no selectable text is found. OCR results improve pairing accuracy for drawings where the filename alone is ambiguous.
  5. Analysis engine runs
    analysis_engine.py compares each Excel row against its paired PDF(s). For each field (sheet_no, sheet_name, revision, revision_date) the configurable authority order determines which source is trusted. Issues are classified by severity.
  6. Review results table
    The Results Tab shows a filterable matrix with per-row status indicators, inline OCR thumbnail previews, and an issue inspector panel with fix suggestions for every flagged item.
  7. Export verification report
    Export the full results as an .xlsx workbook or a formatted .pdf report via reportlab, ready to attach to project correspondence.

Result Severity Levels

✅ OK — all sources match ⚠️ Warning — minor discrepancy ❌ Error — critical mismatch
Key Features Capabilities and modules
Multi-Source PDF Loading

Local folder, individual files, multi-page PDF, or Autodesk Construction Cloud (ACC) via OAuth2 PKCE browser flow.

Excel Register Ingestion

Configurable column mapping, full revision history support. Also reads TIDP drawing registers.

OCR Pipeline

Per-region vector-text extraction via PyMuPDF, with Tesseract fallback and per-region confidence scoring.

Revision Table OCR

Extracts the full revision history table from the titleblock and compares it (not just the latest revision).

Configurable Authority Order

Per-project settings define which data source wins for each field: Excel > Revision Table > Filename > OCR (fully adjustable).

Relationship Manager

GUI editor to define which Excel columns map to which PDF titleblock fields.

Fix Suggestions

Automated explanations and corrective suggestions for every issue type, shown in the issue inspector panel.

ACC / BIM360 Integration

Browse Autodesk hubs → projects → folders → files. Full OAuth2 PKCE flow with an in-app browser login.

Titleblock Profile Editor

Create and edit named JSON region profiles visually via a RegionPickerDialog with zoomable PDF preview.

Export Reports

Full verification report export to .xlsx (via openpyxl) or .pdf (via reportlab).

Tutorial / Demo Mode

Bundled sample data with an interactive walkthrough tutorial dialog for onboarding new users.

Dark / Light Theme

Moon/Sun toggle in the app header; preference persisted per-user.

Menu Bar

Application Tabs

Issue Package Verifier Titleblocks Settings

Verifier Tab — Inputs Panel

  • Load Excel — file picker → Excel Mapping Dialog to configure column assignments
  • Load PDFs / Load PDF Wizard — source selection: folder, multipage PDF, individual files
  • ACC Cloud button — opens ACC Project Browser with OAuth2 login
  • Titleblock profile combo — selects the active region profile for OCR
  • Run OCR / Cancel OCR buttons — triggers/stops the background OCR worker thread

  • Filterable comparison table — per-row status (OK / Warning / Error), with inline OCR thumbnail previews via a custom OcrImageDelegate
  • Issue inspector — click any flagged row to see detailed issue description and fix suggestion
  • Scorecard — summary statistics across the result set
  • Export Excel / Export PDF — generate the verification report

Titleblocks Tab

View, create, and edit named titleblock region profiles. Each profile defines pixel regions on the PDF page for sheet number, revision, revision date, title, etc.

Settings Tab

Per-project configuration for authority order and parser mode. Authority order controls which source wins in a conflict for each field (Excel, revision table, filename, OCR).

Developer Notes Architecture, file structure, and dependencies

Architecture

The app uses a PySide6 QMainWindow with a custom pill tab bar, reactive shared state via ui/app_state.py (Qt Signals/Slots), and a clear separation between UI (ui/) and backend (backend/). The OCR pipeline runs in a dedicated QThread (ui/workers/ocr_worker.py) to keep the UI responsive. Packaged as a standalone .exe via PyInstaller.

Key Backend Modules

  • backend/analysis_engine.py — core comparison and validation logic (analyze_row())
  • backend/models.py — ExcelRow, FileEntry, RevisionEntry dataclasses
  • backend/normalize.py — sheet/revision canonicalisation for comparison
  • backend/pdf_reader.py — fast PDF loading + OCR orchestration
  • backend/ocr/ — OCR sub-modules: sheet OCR, revision OCR, revision table OCR, confidence scoring
  • backend/aps_client.py — Autodesk Platform Services OAuth2 PKCE client
  • backend/fix_suggestions.py — auto-fix suggestion engine
  • backend/titleblock_registry.py — profile discovery and management

User Data Location

AppData-based paths managed via backend/app_paths.py. Stores titleblock profiles, project settings, and cached ACC data.
