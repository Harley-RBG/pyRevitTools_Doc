Issue Package Creator is a drawing and document issue workflow automation tool for engineering teams. It handles the full lifecycle of a formal drawing issue package — from organising exported files into a standardised folder structure, through generating an internal approval binder PDF, to drafting the outgoing Outlook email with fully populated placeholders.

The app eliminates manual steps that are error-prone and time-consuming: renaming folders, sorting files, merging PDFs, and composing emails. Instead, a project context is configured once (paths, contacts, email templates) and the creation process runs with a single click.

Workflow Step-by-step issue package creation process
  1. Set up project context
    Select or load a saved project link — project name, project code, export folder path, principal, and designer. Saved links can be favourited for quick access.
  2. Preview the package
    The app scans the export folder and maps each file to its correct destination sub-folder: Drawings/PDF, Drawings/DWG, or Internal Approvals. The mapping is shown in a table before any files are moved.
  3. Run discrepancy check
    Compares drawing numbers found in the RevisionHistory .xlsx against the exported .pdf / .dwg / .dxf filenames. Missing, extra, and duplicate files are flagged in a colour-coded table. Double-click any row to open the file in Explorer.
  4. Set package title & date
    Choose from saved package titles (e.g. Issued for Construction, Issued for Tender) and pick an issue date via the custom calendar picker widget.
  5. Generate Binder Set PDF
    Merges all package PDFs into a single Internal Approvals/<Binder Name>.pdf, respecting a saved page order that can be customised via drag-and-drop.
  6. Create the issue package
    Creates the dated destination folder in yyMMdd – Description format, then copies or moves all valid files into their correct sub-folder destinations in one operation.
  7. Draft the Outlook email
    Uses a Hybrid / HTML / OFT template with full placeholder substitution (project name, drawing numbers, issue date, contacts, etc.) to create a ready-to-review Classic Outlook draft complete with attachments.
Key Features Capabilities and modules
Package Folder Naming

Dated folder structure uses the yyMMdd – Description format, consistent with standard engineering issue conventions.

Automatic File Routing

.pdf → Drawings/PDF, .dwg/.dxf → Drawings/DWG, RevisionHistory → root, binder → Internal Approvals.

Discrepancy Detection

Flags missing, extra, and duplicate files by comparing RevisionHistory rows against exported filenames before any changes are made.

Binder Set PDF

Merges package PDFs into a single internal approval binder. Page order is configurable via drag-and-drop and is saved per project folder.

Saved Project Links

Reusable project context including folder paths, principal/designer names, and email metadata. Supports favouriting and quick selection.

Address Book

Manage multiple address books with contact autocomplete for To/CC fields. Supports direct import from Outlook contacts.

Email Templates

Hybrid, HTML, and OFT template modes with rich placeholder substitution. Templates are edited in a built-in template editor tab.

Titleblock OCR

PyMuPDF vector-text extraction with Tesseract fallback for ordering pages by drawing number. A portable Tesseract runtime is bundled with the EXE.

Dark / Light Theme

Theme preference is toggled in-app and persisted per-user via ui_settings.json in AppData.

Telemetry

Non-blocking local JSON event log and optional network telemetry for usage tracking and diagnostics.

User Interface Tabs, panels, and key controls

Application Tabs

Issue Package Creator Projects Address Book Email Template

Issue Package Creator Tab (Main)

This is the primary working area. Key controls include:

  • Project combo — select a saved project / export folder path
  • Package title combo — e.g. Issued for Construction, Issued for Tender, Issued for Review
  • Status combo — WIP, IFC, IFA, IFR, IFT, etc.
  • Date picker — custom calendar popup widget for selecting the issue date
  • Preview button — builds the file mapping table without making any changes
  • Discrepancy panel — comparison table; double-click rows to reveal the file in Explorer
  • Create Issue Package — runs the full copy/move operation to create the dated folder
  • Generate Binder Set — merges PDFs into the internal approval binder
  • Outlook Draft — creates a ready-to-send Outlook email draft from the active template

Projects Tab

Manage saved project links: add, edit, delete, and favourite projects. Each entry stores export folder path, project name, project code, principal, designer, and email metadata.

Address Book Tab

Organise contacts into multiple named books. Supports importing contacts directly from Outlook, with deduplication logic to prevent double entries.

Email Template Tab

Rich template editor (lazy-loaded on first visit to avoid WebEngine startup cost). Supports Hybrid, HTML, and OFT template types with a full set of available placeholder tokens.

Developer Notes Architecture, file structure, and dependencies

Architecture

The app uses a PySide6 QMainWindow with a custom pill-style tab bar. UI is split into ui/tabs/, ui/dialogs/, and ui/widgets/. Backend logic lives in backend/ modules with clear separation from UI. The app is packaged as a standalone .exe via PyInstaller with a bundled Tesseract runtime in third_party/.

User Data Location

%APPDATA%\IssuePackageCreator\users\<username>\ — stores saved links, address books, email templates, PDF order files, region settings, and UI preferences.

Key Backend Modules

  • backend/issue_package.py — core package creation and file routing logic
  • backend/issue_package_naming_check.py — discrepancy detection (RevisionHistory vs exports)
  • backend/email_templates.py — template rendering with placeholder substitution
  • backend/outlook_email.py — Outlook COM draft creation via pywin32
  • backend/region_ocr.py — PDF region extraction using PyMuPDF + Tesseract
  • backend/address_book.py — CRUD + deduplication for contact management
  • backend/saved_links.py — project context presets persistence
